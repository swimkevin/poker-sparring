# Screenshots

Drop files here, then uncomment the matching lines in `README.md`.

## Needed

| File | What to capture | Size hint |
|---|---|---|
| `desktop.png` | Mid-hand on desktop: cards dealt, coach tip visible in the side panel | ~1280px wide |
| `mobile.png` | Mobile view (390px wide): table + bottom tab bar visible | 390×844 |
| `demo.gif` | 30–60s: open app → "Deal me in" → coach tip → play a hand → hand replayer | Keep under ~5MB |

## Tips

- **Desktop:** play a cash game until it's your turn with the coach panel showing, then screenshot.
- **Mobile:** use your iPhone (real device beats emulator) — the bottom tab bar is the key element to show.
- **GIF:** QuickTime screen recording → convert with any free GIF tool. Or skip the GIF and link a YouTube video in the README's "Demo video" section instead (unlisted is fine).
- Keep the files small — this repo deploys to GitHub Pages, and large binaries slow every push.
